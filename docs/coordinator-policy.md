# Discretionary delegation and recovery

`agent-dispatcher register` installs the MCP connection and a short shared coordinator policy. Substantial work should be delegated when doing so saves allowance or supplies a capability advantage, without requiring the user to say “dispatch.” Trivial work stays local. Routing is deterministic; ordinary tasks omit `prefer` and `model`. The reserve protects Codex **workers**, not inference in an interactive Codex chat. Instructions influence a model's decisions; they cannot guarantee delegation on every request or impose a hard chat allowance cap.

| Client      | Persistent policy                                                         | Lifecycle behavior                                                                                                                                                                                                                                          |
| ----------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Codex       | `~/.codex/AGENTS.md` (existing `AGENTS.override.md` takes precedence)     | Native instruction chain at session startup. No invented compaction hook. Preserve IDs in handoffs and recover once after resume/compaction.                                                                                                                |
| Claude Code | `~/.claude/CLAUDE.md` and additive `SessionStart` hook in `settings.json` | Hook injects policy, actual origin and bounded saved session work at startup, resume, clear, compact and fork. No inference.                                                                                                                                |
| Cursor      | Global `~/.cursor/hooks.json` `sessionStart` context hook                 | Injects core policy into new conversations. No claim of guaranteed resume/compaction reinjection. A persistent User Rule in Customize → Rules holds the core text for every project on the configured Mac; generic CLI registration installs only the hook. |
| Antigravity | `~/.gemini/AGENTS.md`                                                     | Native always-on global rules; recover once after resume/compaction.                                                                                                                                                                                        |
| OpenCode V2 | `~/.config/opencode/AGENTS.md`                                            | Native global instructions; recover once after resume/compaction.                                                                                                                                                                                           |
| Muse        | Gateway MCP instructions and local handoff                                | Uses gateway-scoped `list_tasks` for recovery. Remote persistent prompt installation must be verified in Muse itself.                                                                                                                                       |

Re-run registration after upgrading to refresh managed sections. Unrelated instructions, JSONC comments, MCP entries and hooks are preserved with backups. `unregister` removes managed policy blocks, generated hooks and exactly matching MCP entries, retaining state and custom entries. Cursor User Rules are managed through its UI; remove the “Agent Dispatcher — coordinator policy” rule there when uninstalling. Restart/reconnect clients after registration; an already-running MCP connection may still advertise the previous tools. Custom global config-directory overrides require installing the policy in that client's effective configuration location.

## Durable recovery

`recover_tasks` takes an actual Codex/Claude `origin`, or an exact `cwd`. It returns active and unacknowledged task IDs, original goals, idempotency keys, ownership, routing and artifact locations. It never launches a model, replays work or acknowledges receipt. Filtering happens before the result limit. Workspace recovery may include other conversations and is discovery, not authorization to act on their tasks. `agent-dispatcher recover /absolute/repository` offers the same bounded lookup locally. This local MCP is trusted user access; session filtering is not a multi-tenant security boundary.

Supply the real origin for completion delivery. Codex can read its own `CODEX_THREAD_ID`; a shared MCP server's environment is not a reliable per-request chat identity. Claude's channel launcher binds the origin. Other clients have an inbox and must not promise unsolicited push. Muse keeps its existing gateway ownership and action policy; it must not expose the local unscoped recovery tool remotely.

The interactive agent is the coordinator regardless of vendor. A spawned dispatcher worker has `AGENT_DISPATCHER_WORKER=1`, empty/isolated MCP and native permissions; it executes its assignment without recursive delegation. Worker artifacts remain untrusted evidence for coordinator review and conflict-preserving patch application.

## Verification

Routine tests use temporary homes and mock workers, including policy preservation/idempotency/removal, session recovery after disconnection, unknown delivery and no duplicate execution. `node scripts/coordinator-smoke.mjs --live` explicitly spends two bounded native Claude subscription coordinator requests: an ordinary implementation request that never mentions dispatch, followed by resume. The worker is synthetic. It checks default routing, the actual origin, receipt acknowledgement and no duplicate task. This is a behavior test, not a guarantee about all future model decisions. Real cross-vendor worker/delivery tests remain separate in `scripts/live-smoke.mjs` and the MCP suite. Do not force compaction by wasting an entire context window.
